# まなびバンク 📚

娘の学習時間と余暇時間を家族で管理するWebアプリです。

- 学習時間を記録すると、その1/4が「余暇可能時間」として自動的に積み立てられます
- 余暇を使ったら余暇利用時間を記録すると、残高から自動的に減算されます

## フォルダ構成

```
study-tracker/
├── README.md
├── frontend/
│   └── index.html        # フロントエンド本体
└── backend/
    └── gas_code.js       # Google Apps Script本体
```

## セットアップ手順

### 1. バックエンド（Google Apps Script）

1. [script.google.com](https://script.google.com) を開き「新しいプロジェクト」を作成する
2. `backend/gas_code.js` の内容をエディタに貼り付ける
3. **1行目の `YOUR_SECRET_API_KEY_HERE` を任意のパスワードに変更する**
   ```js
   const API_KEY = "自分で決めたパスワード";
   ```
4. メニュー「デプロイ」→「新しいデプロイ」を選択する
5. 以下の設定でデプロイする
   - 種類：**ウェブアプリ**
   - 実行ユーザー：**自分**
   - アクセスできるユーザー：**全員**
6. 「Googleが確認していません」という警告が出たら「詳細」→「安全でないページに移動」をクリックする（自分で作ったアプリを自分で使うため安全です）
7. 発行された `https://script.google.com/macros/s/XXXXX/exec` 形式のURLをメモしておく

> ⚠️ GASのコードを修正した場合は、「デプロイを管理」→「編集」→「バージョン：新しいバージョン」で再デプロイが必要です

### 2. フロントエンド（GitHub Pages）

1. このリポジトリをGitHubに作成する（Public）
2. `frontend/index.html` をプッシュする
3. リポジトリの Settings → Pages を開く
4. 以下の設定で保存する
   - Source：**Deploy from a branch**
   - Branch：**main** / **`/frontend`**（ルートではなくfrontendフォルダを指定）
5. 数分後に `https://（ユーザー名）.github.io/study-tracker/` で公開される

### 3. ログイン

公開されたURLをiPhoneで開き、以下を入力してログインする

- **GAS URL**：手順1でメモしたURL
- **パスワード**：手順1で設定したパスワード

一度ログインすると次回以降は自動的にログインされます。

## iPhoneのホーム画面に追加する方法

Safariで開いた状態で、共有ボタン（□↑）→「ホーム画面に追加」を選択するとアプリのように使えます。

---

## バックアップと復元

### バックアップ

「設定」タブ →「JSONバックアップをダウンロード」でその時点の全データをJSONファイルとして端末に保存できます。定期的に実施することを推奨します。

### 復元

「設定」タブ →「バックアップから復元」でバックアップJSONを選択すると、データを復元できます。

> ⚠️ 復元すると現在のデータは上書きされます

---

## GASのコードを変更した場合

コードを変更してもデプロイし直さないと反映されません。以下の手順で再デプロイしてください。

1. GASのエディタでコードを修正・保存する
2. 「デプロイ」→「デプロイを管理」を開く
3. 鉛筆アイコン（編集）をクリックする
4. バージョンを「新しいバージョン」に変更して「デプロイ」をクリックする

## ロジック仕様

| 項目 | 内容 |
|------|------|
| 余暇可能時間 | 累計学習時間 × 1/4（端数切り捨て） |
| 余暇残高 | 余暇可能時間 − 余暇利用時間 |
| 残高がマイナスの場合 | 記録時に確認アラートを表示（記録は可能） |
